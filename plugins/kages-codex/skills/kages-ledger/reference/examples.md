# Recommended examples

Start with review-brief for a general Kage. It keeps the answer, evidence and next steps visible on one reading page. Adapt the content and omit unnecessary regions. Choose a specialized example only when its task calls for it. These are editorial recommendations, not measured rankings.

- [review-brief](examples/review-brief.kage.json) — Default: a readable verdict, facts, findings with evidence and fixes, next action, verified checks and order of work.
- [research-brief](examples/research-brief.kage.json) — A sourced argument that needs quotations, figures and references.
- [growth-lab](examples/growth-lab.kage.json) — A calculator when changing an assumption must change the result.
- [event-planner](examples/event-planner.kage.json) — A task that needs validated reader input and a submitted result.
- [signal-field-guide](examples/signal-field-guide.kage.json) — A handbook that readers revisit by chapter and search.

Selection bar: a clear first-screen takeaway, evidence beside claims, useful density, honest limits, complete resting content and mobile/dark review. Controls must change a real result.

[Full example library](examples-all.md) — capability demonstrations and advanced patterns; not the default starting list.
